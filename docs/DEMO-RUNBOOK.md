# Three-minute demo runbook

Record a real run. Live model calls can take longer than three minutes: record the whole session and trim waiting time, explicitly labelling any cut. Do not substitute saved outputs for execution.

**0:00–0:20 — The problem.** “A dispatch plan is only as good as the facts underneath it. AFTERSHOCK keeps each commitment attached to the evidence that makes it possible.” Identify the user as a relief logistics coordinator, the district as synthetic, and the track as Reasoning Architecture.

**0:20–1:00 — Create a commitment.** Start with clear reservations and an open Cendana bridge. Request north 60 and east 50 kits, leaving south and west at zero. Show the actual query and proposal trace. On a fresh world state, the maintenance ledger contradicts V1's available roster entry, and the Challenger requests revision. On subsequent runs, the learned exclusion changes the first proposal; explain that difference honestly.

**1:00–1:40 — Break the plan.** Select the north order and show its bridge dependency. Close the bridge using the ordinary source control. Show the hold, the revised proposal, and the replacement reservation. Compare the east order ID before and after: it should remain unchanged. The demonstrated result depends on current fleet, stock and deadline; use the real outcome.

**1:40–2:20 — Show the engineering.** Expand a Zetaris query and a model-call event. Explain the World Model's versioned evidence and the Markovian revision limit. Show deterministic checks rejecting unsupported quantities or stale evidence before a reservation can be released. Do not present the engine's text estimates as measured token savings.

**2:20–3:00 — The result.** Show the replacement route, linked evidence and an unaffected order. Optionally recheck and release one sandbox reservation. “A broken assumption changes the affected commitment; the other work stays intact.” State the limits: a fictional district, one dispatch wave and synthetic actions.

For a credential-free rehearsal, use sample mode and say explicitly that it runs deterministic agent policies. Use live mode for evidence of sponsor model calls. The saved files in `diagnostics/` document earlier actual executions; they are not runtime answers.
