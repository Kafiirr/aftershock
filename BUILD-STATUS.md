## Reproduce

```bash
npm ci
npm run check
npm test
npm run test:engines
npx tsx scripts/generate-examples.ts
```

The three example outputs are generated by executing the sample engine. Runtime does not read them. Optional browser automation is in `scripts/browser-check.cjs`; it expects a fresh sample instance on port 4319, Playwright and Chrome. Set `PLAYWRIGHT_MODULE` and `CHROME_PATH` for your installation.

## Operational limits and remaining submission work

Live mode depends on the Windows Nightshift runtime and all required Zetaris containers, including the driver. The driver was found stopped after the environment restart; the application correctly blocked the next mission before reserving anything. The driver was restarted, and authenticated SQL plus Nightshift discovery passed again at 13:20 UTC; see `diagnostics/providers-final.json`. Server health alone is not a provider connectivity check. Run `npm run diagnose` to verify providers.

This is a synthetic sandbox with bounded greedy search, not field-validated dispatch software. Sample mode uses deterministic policies, not model calls. Reservations expire after fifteen minutes and departed orders are not automatically repaired. Public hosting, a public GitHub repository, a slide deck, a recorded demo and the competition submission have not been created. Declare the vendored sponsor components and verify current submission rules before entering.
